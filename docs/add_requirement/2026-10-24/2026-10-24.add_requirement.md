# 2026.10.24 追加仕様
## 1. 要求
### 1.1. 要求 Phase1
- 今後、複数のオーケストレーターとエージェント、サブエージェントを追加したい。
- オーケストレーターとエージェント、サブエージェントは一覧管理がしたい。
- オーケストレーターとエージェント、サブエージェントは、一意に管理できるようにID管理をしたい、UUIDなどで良い。
- オーケストレーター、エージェント、サブエージェントを認証・認可コントロールをしたい。イメージはMicrosoft Agent 365。ただし、個人利用なので、認証が不要なら追加する必要なし。
- 複数のエージェントを管理するようになるので、新しくポータル化したUIを追加。
- 今後、追加するエージェントは、Dockerコンテナを追加してDocker composeで起動するので、UIから起動・停止管理もしたい。
- フロントエンドとバックエンドでロジック分離してほしい。
- バックエンドはPython、フロントエンド現行の言語で問題ない。

### 1.2. 要求 Phase2
- Phase1を踏襲。
- Azure専用にしたが、今あるAzure調査用のエージェント群を残したまま、新しい上位のオーケストレーターを作成。
- プロジェクト名は猫神さま(NekoGamiSama)
- 猫神さまエージェント（オーケストレーター）が全部のサブオーケストレーター及びエージェントを管理する。
- 最初のAzure調査用のエージェントは猫神さまのサブオーケストレーターとする。
- 各エージェントのトレースログに出力される言葉には、最後に「にゃ」をつける。

### 1.3. 要求 Phase3
- 猫神さまのエージェントは消せない様にする。（管理者エージェント）
- 猫神さまは、専用の管理ページで管理できる様にする。
- 管理ページは、ポータルから移動できる様にする。
- ポータルの一覧にはさブオーケストレーター以下を表示する。
- エージェントは、ツリー表示されトグルで表示、非表示ができる。
- サブオーケストレーター、エージェントはノードグラフで新規追加、削除、ツール接続ができる（Unreal EngineなどのBlouePrint編集のような）
- サブオーケストレーター、エージェントはノードグラフ編集のなかでモデルを選択できるようにする。
- ポータル画面に猫神さまとチャットして会話できる入力エリアを用意する。

### 1.4. 要求 Phase4
- cluadeを利用したサブオーケストレーターとエージェントを追加できる様にして欲しい。
- モデル選択、プロンプト入力、ツール選択はノードから編集できる様にして欲しい。
- .claude/agents下で体系的にエージェント管理できる様にして欲しい。
- nekogamisama/suborchestrators.jsonを管理ページの委任先突き合わせで台帳と委任設定を編集できる様にしてほしい
- サブオーケストレーター、エージェント、ツール、サブエージェントはノードの編集画面で右クリックすると表示されるメニューから新規追加できる様にして欲しい。
- サブオーケストレーター、エージェント、サブエージェントの名前を編集できる様にして欲しい。
- 猫神さまとのチャットでとのエージェントが選択されたのかをトレースをポータル画面で可視化できる様にして欲しい。

### 1.5. 要求 Phase5
- dashboardのAzure Sage Consoleの名称を変更し、Agent Consoleにする。
- Agent Consoleを他のサブオーケストレーターでも使用できるように変更する。
- dashboardは使用するエージェント毎にフローが変更される様にする。
- dashboardはポータルのサブオーケストレーターの一覧から専用のボタンでダイアログとして表示される様にする。
- ポータルのチャットとサブオーケストレターの一覧をマウスで配置変更できる様にし、サイズも変更できる様にする。
- 猫神さまが委任しているサブオーケストレターをフロー図とトレースログで表示する。
- 猫神さまの性格を設定できる様にする

## 2. 作成するドキュメント

- docs/adr, docs/changes, docs/licenses, 必要に応じて新しいフォルダにまとめる。

## 4. 制約条件
