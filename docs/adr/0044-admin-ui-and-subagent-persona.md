# 0044 管理ページの見直しと、サブオーケストレーターの性格

- 状態: Accepted（性格の保存先は [0046](0046-subagent-personality-file.md) で、personality.md を正とする形に更新）
- 関連: [0021](0021-nekogamisama-personality.md)（猫神さまの性格）、[0042](0042-nested-suborchestrators.md)、[0043](0043-agent-calls-and-auto-spawn.md)、要件 [rev3](../requirements/20261025-rev3-admin-ui-and-persona.md)

## 決定
### 左の列の開閉
- 管理ページ左の列（猫神さま・ユーザー・テーマ・性格・委任先・選択ノードのプロパティ）を、ボタンで開閉する。**既定は開く**（rev3 更新で変更。[0045](0045-python-node-body-only.md)）。開閉はブラウザの `localStorage` に保存する（保存できなければ開いたまま）。各カードは個別にも開閉できる（既定は閉じる）。閉じている間も、右クリック →「編集…」のダイアログで、担当のプロパティを編集できる。

### 右クリックメニュー
- 追加できるノードの種類は、ツールバーと同じ一覧（`NODE_ADDS`）から作る。種類を足したときの更新漏れを防ぐ。
- 背景: 担当 3 種と、ノード 5 種（ツール・ディレクトリ・ローカル LLM・Python・入力）。担当: 編集・アイコン・プロパティを開く・配下の追加・ノードの追加・名前の変更・自動作成の許可／禁止（定義ファイルのあるサブオーケストレーター）・削除。ツール: プロパティを開く・追加・削除。ワイヤー: 接続の種類（ツール／入力／呼ぶ）ごとに外す。親子のワイヤーは外せず、案内を出す。

### サブオーケストレーターの性格
- 猫神さまの `personality.md`（`@` で取り込み）と同じ項目（一人称・呼びかけ・口調・性格）を、**定義ファイルの本文の「## 性格・話し方」の節**に書く。サブエージェントは `@` 取り込みを使えず、定義ファイルが唯一の入力になるため。
- 検査（文字数、見出しの禁止、`@` の置換）は猫神さまと同じ。節には「言葉づかいにだけ使い、事実・出典・手順は変えない」の注記を付ける（0021 と同じ原則）。
- 手で書いた「## 性格」の節も、同じものとして読む。保存すると「## 性格・話し方」に置き換える（節は 1 つのまま）。ほかの節はそのまま残す。
- 対象は、定義ファイル（`.claude/agents/`）のあるサブオーケストレーター。`azure-sage`（`CLAUDE.md`）などは対象外（API は 400）。API: `GET/PUT /api/entities/{id}/personality`。

### ノードの参照用プロパティ
- グラフのノードに、ツール数・配下の数・状態を出し、ホバーで全文を出す。編集はしない。プロンプトは含めない（長く、機密を含みうるため）。表示のための計算は、画面の純粋関数（`entityProps` / `entityDetail`）。ノードが高くなるので、自動配置の行間を広げた。

## 影響・注意
- 性格は、サブオーケストレーター自身の返答にだけ効く。猫神さまがそれをまとめるときは、猫神さまの口調になる。
- 試験: 性格の読み書き・置き換え・検査・対象外（API）、プロパティの表示（画面）。
