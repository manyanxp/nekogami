# 0047 Shared Principles（サブオーケストレーターから直下の子へ渡す共通プロンプト）

- 状態: Accepted
- 関連: [0046](0046-subagent-personality-file.md)（同じ「ファイルを正にして、定義へ自動同期」）、要件 [rev4](../requirements/20261025-rev4-shared-principles.md)

## 決定
- 共通プロンプトの正は `nekogamisama/shared/<親の名前>/shared-principles.md`。定義ファイルのあるサブオーケストレーターが持つ。
- 子ごとに「使う」をチェックボックスで選ぶ。**使う子の定義ファイル本文に「## Shared Principles（全エージェント共通指示）」の節を自動生成**する（自動生成と明記するコメント付き）。子は起動時から、自分のプロンプトと合わせたものを読む。追加の読み込みも Read ツールも要らない。
- 使うかどうかの状態は、台帳ではなく**定義ファイルに節があるか**で決める。台帳が作り直されても、状態が失われない。
- 届く範囲は**直下の子だけ**（エージェント・子サブオーケストレーター）。孫へは、子のサブオーケストレーターが自分の共通プロンプトを持って渡す。猫神さま直下の担当と、定義ファイルのない担当は対象外。
- 同期のタイミング: 保存、チェックの切り替え、API の起動時、親の付け替え・名前の変更・削除。親がサブオーケストレーターでなくなった子は、節が外れる。名前の変更でフォルダも移り、削除で trash へ退避する。
- 検査（4000 文字まで、見出し `#` の禁止、`@` の置換）は性格と同じ考え方。API: `GET/PUT /api/entities/{id}/shared`（`{text}` で本文、`{use}` で子の切り替え）。

## 影響・注意
- 節を直接書き換えても、次の同期で上書きされる。直すのは `shared-principles.md`。
- 試験: 本文の保存・子への反映・追従・外す・孫に渡さない・付け替え・検査・名前の変更（API）。
