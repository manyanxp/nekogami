# 0033. エージェントごとのターミナル窓（ポータル）

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev3 の要求: トレースの画面を、サブオーケストレーター・エージェントごとに、SF のように動かせるターミナル UI で表示する。終了したら自動で閉じ、任意で手動でも閉じられる。

## 決定
- **対象**: 猫神さまのチャットのトレース（ADR 0019）に現れた呼び先（`trace.agents` の各名前）。1 つの呼び先に 1 つの窓。
- **開く**: その呼び先の実行回数（`statsOf` の `inst`）が増えたとき。開始から終了までが 1 回の更新にまとまっても開く。同じ相手をもう一度呼ぶと、開いている窓をそのまま再利用して前面に出す。
- **自動で閉じる**: 実行中でなくなったら、窓に「■ 終了（自動で閉じます）」と出し、5 秒後（`CLOSE_AFTER`）に閉じる。その間に再び呼ばれたら、閉じるのをやめて実行中の表示に戻す。トレースがリセットされたときも、同じ流れで閉じる。
- **手動で閉じる**: 窓の ✕。次に呼ばれるまで開き直さない。
- **移動・サイズ**: タイトルバーのドラッグで移動（Pointer Events。画面の外に出きらないよう補正）、右下の角で大きさを変更（CSS の `resize`）。クリックで前面に出す。
- **中身**: その相手の行だけ（その相手のツール呼び出し・開始・完了と、その相手が選ばれた行。`LogLine.to` を足した）。暗い背景に緑の文字、走査線、実行中は点滅するカーソル。`prefers-reduced-motion` ではアニメーションを止める。
- 実装: 純粋ロジックは `web/src/lib/terminal-model.ts`（vitest で 6 件）、窓は `web/src/components/TerminalWindows.tsx`。新しい依存はない。既存の「トレース」パネルは、そのまま残す（全体の時系列）。

- **開く位置（rev3 追加）**: 左上（x=16, y=64）から。開いている窓と位置が重なるときは、右下へ (28, 34) px ずつずらす（6 つで一巡）。閉じた窓の位置は次の窓が再利用する（`freeSlot`）。
- **閉じるまでの待ち（rev3 変更）**: 3 秒 → 5 秒。
- **パラレル実行（rev3 追加）**: 同じ担当の同時実行は、窓 1 つのまま、全部が終わるまで「実行中」（`inst > fin`）。サーバー（Agent Console）は担当ごとに別々に同時に動け、並列にするかどうかは猫神さまの指示（`nekogamisama/CLAUDE.md` の標準ワークフロー）で決める。独立した依頼は同じ応答で Agent ツール（session 型は Bash）をまとめて呼ぶ。

## 理由・検討した代替案
- ターミナル風の外部ライブラリ（xterm.js 等）: 入力・エスケープシーケンスの端末エミュレーションは不要で、ログ表示だけなので、依存を増やさず CSS で作った。
- 窓の状態を「実行中」だけで判定する案: 短時間で終わる呼び出しが、開始と終了を同じ更新で受けると窓が開かない（実際にブラウザで確認して、実行回数の増加で判定する方式に直した）。

## 影響・注意
- ページを開いた直後にトレースが再生される（replay）場合、終わった呼び出しの窓が開き、5 秒で閉じる。
- 窓は、猫神さまのチャットのトレースだけが対象。Agent Console（`/console`）には出ない。
