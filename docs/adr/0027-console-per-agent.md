# 0027. エージェントごとの Agent Console

- 状態: Accepted
- 日付: 2026-10-24

## 背景
`.claude/agents/` にあるエージェントごとに、別々のコンソールで話したい、との要望。それまでの Agent Console の「相手」は、猫神さま・Azure Sage・委任先一覧（`suborchestrators.json`）の項目だけで、個別のエージェントは出なかった。また、応答中の管理が全体で 1 つ（`running`）で、別の相手のコンソールを同時には使えなかった。

## 決定
- **相手の追加**: `.claude/agents/` 配下（3 階層まで）の定義ファイルをすべて `agent` 型の相手にする（`buildTargets`）。メインスレッドをそのエージェントにして、プロジェクトのルートで実行する（SDK の `agent` オプション、ADR 0020）。委任先一覧と同名のものは上書きしない。
- **猫神さまのフロー図のチーム**は、これまでどおり委任先だけ（定義由来の相手は含めない）。
- **同時実行**: 応答中の管理を「相手ごと」にする（`running` は相手 → AbortController の Map）。同じ相手への 2 つ目の送信だけ 409。別の相手とは同時に動く。
- **フックの振り分け**: フックの `session_id` が相手のセッション ID と一致するものを、その相手の会話の出来事にする。一致がなく、応答中が 1 つだけならその相手とする。複数同時で判定できないものは印なし（既定の相手の扱い）。許可・サブエージェント発話は、相手を明示して送る。
- **停止・リセット**: `/api/stop` は `agent` を指定するとその相手だけ止める（省略時は全部）。リセットは、指定した相手が応答中でなければできる。
- **画面**: 応答中かどうかは相手ごとに表示する（`hello` に `runningTargets`）。ポータルは、Console が相手にできる全エンティティに「🖥 Console」を出す。ポータルのチャットの停止は猫神さまだけを止める。

## 理由・検討した代替案
- エージェントごとに別のサーバーを起動する案: ポート管理と起動・停止が相手の数だけ増える。1 つのサーバーで相手ごとに画面と応答を分ければ足りる。

## 影響・注意
- 個別のエージェントを相手にすると、そのエージェントがメインスレッドになる。`Agent` ツールがなければ、他のエージェントは呼べない。ルートの `CLAUDE.md` も読み込まれる。
- 複数の相手が同時に動くと、`session_id` が合わない CLI や別セッションのフローは、印なしになることがある。
- **未確認**: 実際の Claude での、定義ファイル由来の相手との会話・同時実行（認証が必要なため。フック振り分けと相手一覧は単体テストと構文確認のみ）。
