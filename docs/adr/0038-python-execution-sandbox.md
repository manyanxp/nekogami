# 0038. Python の生成・実行（実行役のコンテナと、ディレクトリのノードの「Python 実行」権限）

- 状態: Accepted
- 日付: 2026-10-25

## 背景
rev1 の要求: 担当が Python のコードを生成・実行できるようにしたい。管理ページのノードグラフで管理する。追加の指示: numpy・pandas などのデータ分析ライブラリを使えること、**ディレクトリのノードで許した場所で作業させること**。

コードの実行は、ファイルの読み書きより危険が大きい（任意のコードが動く）。実行環境を分け、見せるものを絞る。

## 決定
- **権限**: ディレクトリのノード（[0037](0037-directory-nodes-and-permissions.md)）に 5 つ目の権限 `exec`（画面では「Python 実行」）を足す。既定はオフ。担当には MCP ツール `run` として見え、`mcp__dir-<名前>__*` でつなぐ点は他の操作と同じ。**どのディレクトリで作業できるかは、つないだノードで決まる**。書き込み・削除と同じく、新しくつなぐときは確認が要る。
- **実行役**: 専用コンテナ `py-sandbox`（`sandbox/`）。`network_mode: none`、読み取り専用、非 root（1000）、`cap_drop: ALL`、`no-new-privileges`、メモリ 512 MB、プロセス 128、CPU 1。Docker のソケットは渡さない。
- **やり取り**: ネットワークではなく、共有フォルダ `sandbox/jobs/` のジョブで行う。Agent Console が `<id>/` に `code.py`・`work/`・`job.json` を置き、実行役が 1 件ずつ取り出して実行し、`result.json` を書く。実行役は、このフォルダしか見えない。
- **ノードの中だけで作業**: 実行役には、ノードの中身の**コピー**だけを渡す（`work/` が作業ディレクトリ）。ノードの外のファイルは、渡さないので見えない。
  - 読み込みの権限がなければ、コピーは空。シンボリックリンクと、2 MB を超えるファイルは渡さない。合計 20 MB・500 ファイルまで。
  - 実行後、`work/` の変更を、**権限の範囲だけ**ノードへ戻す。新規・更新は書き込みの権限があるとき（1 ファイル 5 MB、200 ファイルまで）、削除は削除の権限があるとき。戻さなかったものは、理由つきで結果に書く。戻すときは、書き込み・削除と同じ検査（実体のパスがノードの中にあること）を通す。シンボリックリンクは戻さない。
- **上限**: 実行 30 秒（超えたらプロセスごと停止）、標準出力・標準エラーは各 100 KB、コードは 100 KB、1 ファイルの書き込み 10 MB、アドレス空間 1 GB（実メモリは 512 MB）。
- **使えるライブラリ**: 標準ライブラリ、numpy、pandas、scipy、matplotlib、scikit-learn、openpyxl（すべて BSD・MIT 系。`docs/licenses/`）。ネットワークがないので、追加のインストールはできない。足すときは `sandbox/Dockerfile` を直して作り直す。
- **担当**: `py-analyst`（`.claude/agents/nekogamisama/py-analyst.md`、猫神さまの直下）。初期の `tools` は `TodoWrite` だけで、ノードをつなぐまで何もできない。つなぐのは管理ページのノードグラフ。
- **定義ファイルの掃除**: ディレクトリのノードを消すとき、担当の定義ファイルから `mcp__dir-<名前>__*` も外す。残すと、同じ名前で作り直したノードが、確認なしでつながってしまうため（実機の確認で見つけた）。

## 検証
- 試験: 実行役の代わりを置いた単体試験（権限ごとのコピー・戻し、リンク、時間切れ、上限）6 件と、API の確認（`exec` も要確認）。
- 実機（本物の実行役）: pandas の集計と画像・CSV の出力、ネットワークの遮断（`Network is unreachable`）、無限ループの 30 秒停止、2 GB の確保が `MemoryError`、読み取り専用の FS、100 KB を超える出力の切り詰め。
- 実機（本物の Claude）: `py-analyst` に、売上 CSV の地域別・月別の集計と棒グラフの保存を依頼。数字は手計算と一致し、`chart.png` と `summary.csv` がノードの中にできた。

## 影響・注意
- **完全な隔離ではない**。ネットワークなし・非 root・読み取り専用・上限つきで守るが、コンテナはカーネルを共有する。悪意のあるコードを動かす用途には、gVisor などの強い隔離を足すこと。
- 実行コードは、`py-sandbox` のジョブ置き場の中を見られる。ジョブは 1 件ずつ実行して、終わったら消すので、同時に見えるのは自分のものだけ（残ったものは、次の実行のときに 10 分で掃除する）。
- 実行は 1 件ずつ。順番待ちを含めて 150 秒で諦める。
- `py-sandbox` が止まっていると、`run` は「応答しない」と返す。
- 猫神さま自身と、別セッション型の委任先（`delegate.sh`）には使えない（0037 と同じ）。
- 依存の追加: 実行役のイメージ（`python:3.12-slim` + 上のライブラリ）。公開はしない（利用者が作る）。
