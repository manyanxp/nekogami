# 0029. 回答のマークダウンプレビュー・コピーと、構成図の HTML 表示

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev2 の追加要求: 猫神さまの回答のマークダウンをプレビューでき、コピーできること。回答に構成図があるときは、HTML でも表示できること。

## 決定
- **自前の軽量レンダラー**（`portal/frontend/js/markdown.js`）。見出し・段落・箇条書き・番号リスト・表・引用・水平線・コードブロック・太字/斜体/打ち消し/インラインコード・リンクに対応する。ポータルのフロントは外部ライブラリなしの方針（ADR 0014）なので、marked などは入れない。
- **安全**: 入力はすべてエスケープし、生の HTML は解釈しない。リンクは `http(s)` のみ。
- **プレビューとコピー**: 回答の完了（`idle`、次のメッセージの開始、再接続時の再描画）でプレビューに切り替える。ストリーミング中は文字のまま。吹き出しの上に「Markdown（元の文との切り替え）」と「コピー」。コードブロックにも「コピー」。コピーは Clipboard API、使えないときは `execCommand`。
- **構成図**: ` ```html ` と ` ```svg ` のコードブロックを「図」として、`sandbox`（スクリプト・同一オリジン不可）付きの iframe の `srcdoc` に出す。文書側にも CSP（`default-src 'none'; style-src 'unsafe-inline'; img-src data:`）を入れ、外部読み込みを止める。「コード」ボタンで図とコードを切り替える。高さは 280px（縦にリサイズ可）。
- **猫神さまへの指示**: `nekogamisama/CLAUDE.md` に、マークダウンで書くことと、構成図は ```html にインライン SVG で書くこと（スクリプト・外部読み込み・Mermaid は不可）を追加した。

## 理由・検討した代替案
- Mermaid: 図が描ける利点はあるが、ライブラリ（MIT）の同梱が大きい。要求が「HTML による表示」なので、SVG/HTML で足りる。
- marked + DOMPurify（Console と同じ）: 動くが、ポータルに依存を持ち込む。必要な記法は少なく、自前で足りる。

## 影響・注意
- 対応していない記法（入れ子の本格的なリスト、脚注、HTML の直書き）は、文字のまま出る。
- 図の HTML は表示専用。サンドボックスのため、リンクのクリックやアニメーションの JS は動かない。
