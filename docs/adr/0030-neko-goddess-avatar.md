# 0030. 猫神さまのアイコン

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev2 の追加要求: 猫神さまのアイコンを `icons/cat-goddess-icons/sun_cat_goddess.png` にする。原画は 1254×1254・約 2.7MB で、アバターには大きい。

## 決定
- 原画から、192×192 の PNG（透明背景のまま）を `scripts/make-avatar.py`（標準ライブラリだけ。アルファ重み付きの面積平均）で作り、ポータル（`/img/neko-goddess.png`）と Agent Console（`/neko-goddess.png`）に置く。原画（`icons/`）は Docker のイメージに入れない（`.dockerignore`）。
- 使う場所: ポータルのチャットの相手のアイコン（絵文字の 🐱 の置き換え）と考え中の行、Agent Console で相手が猫神さまのときの、フロー図の指揮役のカード。ほかの相手・エージェントの猫アイコンは、従来のままにする。

## 理由・検討した代替案
- 原画をそのまま配信する案: 1 枚 2.7MB で、チャットの行ごとに表示すると重い。
- 画像ライブラリ（Pillow 等）で縮小する案: 新規依存になる。標準ライブラリで足りた。

## 影響・注意
- **画像の利用条件は要確認**: README によると、画像生成ツール（組み込みの image_gen）で作られている。商用利用・再配布の可否は、その生成ツールの規約による。公開・配布の前に確認する（ライセンス台帳に「要確認」で記載）。
- 原画の README は、表示サイズ 128px 以上を推奨している。チャットの 36px では細部が潰れる。大きく出す場所を作るなら、192px の版を使える。
