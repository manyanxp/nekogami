# 0026. チャットボットエージェント（neko-chat）と / コマンド

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev2 の要求 H1〜H4: 猫神さまとのチャットボットエージェントを追加し、ポータルでやり取りでき、`/` コマンドでサブオーケストレーターとエージェントを呼び出せ、猫神さまの性格が反映されること。

## 決定
### チャットボットエージェント `neko-chat`
- `.claude/agents/nekogamisama/neko-chat.md`（ADR 0016 の規則どおり、猫神さま直下の `agent`）。モデルは haiku、ツールは `Read, Glob, Grep`（読み取りのみ）。
- 役割: あいさつ・雑談・使い方の説明・「あなたは誰」。調査・提案は担当外（言い直して猫神さまに返す）。
- **性格の反映**: 会話の前に `personality.md`（作業ディレクトリが `nekogamisama/` のとき）または `nekogamisama/personality.md` を Read し、書かれた一人称・呼びかけ・口調・性格で話す。設定を変えれば、`neko-chat` の話し方も変わる（ADR 0021）。
- 猫神さま（`nekogamisama/CLAUDE.md`）は、おしゃべりの依頼を `neko-chat` に Agent ツールで任せ、**言葉づかいを変えずに**返答をそのまま返す。

### `/` コマンド
- **候補の一覧**（`GET /api/chat/commands`）: 猫神さまの委任先（`suborchestrators.json` の各項目。種類は agent / session）と、定義ファイルのあるエージェント（委任先と同名のものは除く）。各項目は、呼び方（`bin/delegate.sh` か、`Agent ツール、subagent_type=…`）を持つ。
- **入力欄**: `/` で始まり、まだ名前を打っている間は、候補（前方一致、次に部分一致）を出す。↑↓で移動、Enter / Tab / クリックで `/名前 ` を挿入、Esc で閉じる。`/help` は、候補の一覧を会話欄に表示する（送信しない）。
- **送信**（バックエンドで展開）: `/名前 依頼文` → `[指名: 名前（呼び方）]` の次の行に依頼文、として猫神さまに送る。
  - 猫神さまは、`[指名: …]` で始まるメッセージを、括弧内の方法で**必ずその相手に依頼する**（別の相手に振り替えない）。
  - 名前は一覧にあるものだけ（未知のコマンドは 400 で、Agent Console に送らない）。依頼文が空でも 400。`/` で始まる普通の文（パスなど）は、**先頭に空白を入れて送る**。名前は `[A-Za-z0-9][A-Za-z0-9._-]{0,63}` に限る（指示文に任意の文字列を入れさせない）。
- ポータルのチャットは、これまでどおり猫神さま固定（ADR 0015）。`/` コマンドは、猫神さまを通して相手を呼ぶ（トレースとフロー図に出る）。

## 理由・検討した代替案
- `/` コマンドで、ポータルが直接サブオーケストレーターを実行する案: 実行基盤・権限制御・トレースが Agent Console に集まっている（ADR 0015）。猫神さまを通せば、フロー図・トレースがそのまま使える。
- `neko-chat` をポータルのチャットの直接の相手にする案: 委任ができなくなる（調査・提案の依頼に答えられない）。猫神さまが振り分ける形にした。
- クライアント側で `/` を展開する案: 候補の一覧とコマンド名の検証をサーバー側に置く方が、一貫して検証できる。

## 影響
- 良い点: 自由な会話は haiku の `neko-chat` で安く済み、依頼は指名できる。
- 制約・注意:
  - **猫神さまが指名やおしゃべりの指示に従うかは、モデルの挙動に依存する**（プロンプトで指示している。強制ではない）。実際の会話での確認は未実施。
  - おしゃべりは、猫神さま → `neko-chat` の 2 段になる（応答が少し遅くなる）。
  - 指名のメッセージは、会話欄にも `[指名: …]` つきで表示される。
- 確認: 実際の `claude -p --agent neko-chat` で、性格の設定（一人称「わし」・「〜じゃ」口調）が返答に出ることを確認した。コマンドの展開・検証・候補は、バックエンドのテストとブラウザの操作で確認した。
