# 0022. ポータルの画面配置の変更と、委任のフロー図

- 状態: Accepted（画面配置と、フロー図の表現は [ADR 0024](0024-portal-panels-and-flow-view.md) に置き換えた。委任先の状態の決め方などは有効）
- 日付: 2026-10-24

## 背景
Phase 5 の要求 F3・F4。ポータルは「一覧（左）+ チャット（右）」の固定配置だった。また、猫神さまが誰に委任したかは、トレースのログとチップでしか分からなかった（ADR 0019）。

## 決定
### 画面配置（`js/layout.js`、純粋ロジックは `layout-model.js`）
- ペインは「一覧」と「チャット」の 2 つ。チャットの位置（`data-dock`）は 右 / 左 / 上 / 下 の 4 通りで、CSS の grid が並びを決める。
- **配置換え**: 各ペインのヘッダー（⠿ の付いた行）をドラッグし、画面を対角線で 4 分割した領域（上・下・左・右）に落とす。ドラッグ中は、置く位置をオーバーレイで示す。チャットを落とした辺がチャットの位置、一覧を落とした辺なら、その反対側がチャットの位置。ボタンなどの操作部品の上や、6px 未満の移動は、ドラッグにしない。
- **サイズ変更**: 2 つのペインの間のバー（`splitter`）をドラッグする。左右のときは幅、上下のときは高さ（範囲は、幅 280px〜全体−320px、高さ 200px〜全体−220px）。ダブルクリックで既定（幅 400px、高さ 420px）に戻す。
- 状態（位置・幅・高さ）は `localStorage` に保存。壊れた値は既定に戻す。保存できない環境でも動く。800px 以下の幅では、縦に積む（配置換えは無効）。
- チャット欄の下の「委任のフローとトレース」の高さも、枠の右下のつまみで変えられる。

### 委任のフロー図（`js/flow.js`、データは `flow-model.js`）
- チャット欄の下の「委任のフローとトレース」を、2 つのタブにした。「フロー図」（既定）と「トレースログ」（ADR 0019 のチップと時系列）。
- フロー図は、猫神さま → 委任先 → その配下の 3 列の SVG。
  - 委任先: 委任設定（`suborchestrators.json`）で **wired** の項目。session 型は別セッションの指揮役、agent 型は呼ぶエージェント。台帳の種別で色分け。
  - 配下: 台帳で「委任先の名前」または「`agent` が指す先」のエンティティの子。
  - 会話中に選ばれたもの（トレースの `route`・`SubagentStart`）は、枠が光り、状態（● 実行中 / ✓ 完了）とツール回数を表示。使われた辺は太く光る。**委任先の状態は配下から決める**: 配下に実行中があれば実行中、動いたものがあって実行中がなければ完了（委任先自身のイベントが届かなくても光る）。
  - **委任設定にない呼び先**（猫神さまが委任先を通さず、エージェントを直接呼んだ場合）は、破線の動的ノードとして足す。
- データの取得: `GET /api/admin/overview`（委任設定）と `GET /api/entities`（台帳）。新しい依頼のたびに更新する。
- 新規依頼ごとにトレースを切り替える（最新の依頼）のは、ADR 0019 のとおり。

## 理由・検討した代替案
- ペインをウィンドウのように自由に浮かべる案: 2 ペインの個人用 UI には過剰で、重なりやはみ出しの処理が増える。4 方向のドッキングで、配置とサイズの要求を満たせる。
- フロー図を管理ページのグラフに重ねる案: 管理ページは構成の編集の場。会話中の流れは、チャットのすぐ下で見られる方がよい。
- フロー図に外部ライブラリを使う案: 3 列の固定レイアウトで、SVG の自作で足りる（ADR 0014 と同じ方針）。

## 影響
- 良い点: 好きな配置で使える。委任の構成と、実際に選ばれた経路が、同じ図で分かる。
- 制約・注意:
  - フロー図は 3 列まで（委任先の配下の、さらに配下は出さない）。ズーム・パンはない。
  - フロー図の「光る」は、トレース（応答中のフック）に依存する（ADR 0019 の制約と同じ）。
  - 実際の Claude の会話でのフロー図は未確認（偽の SDK とフックで、実物のサーバーとブラウザを通して確認した）。
