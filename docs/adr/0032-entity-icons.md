# 0032. エージェントのアイコン（変更・アップロード・既定）

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev2 の追加要求: 猫神さま・サブオーケストレーター・エージェントのアイコンを変更できるようにし、エージェントの既定を `icons/cat-goddess-icons/miko_cat_goddess.png` にする。選択に加えて、画像のアップロードも必要（利用者の指定）。

## 決定
- **台帳の `icon`**: 参照文字列 `builtin:<名前>` / `upload:<ID>`。`null` は既定（種別ごと）。既定は、猫神さま（orchestrator）= `builtin:sun_cat_goddess`（ADR 0030 と同じ絵）、ほか = `builtin:miko_cat_goddess`。参照は台帳（`portal/data/registry.json`）に保存し、検証して保存する（存在しない参照・パスらしい文字列は 400）。
- **組み込み**: `scripts/make-avatar.py` が原画（`icons/cat-goddess-icons/`、1254px）から 192px の PNG（約 90KB）を `portal/assets/icons/` に作る（miko / sun / munakata の 3 種）。原画は配信しない。
- **アップロード**（`POST /api/icons`。本文は画像のバイト列そのもの。multipart は使わず、新しい依存を足さない）:
  - 種類は**中身の先頭バイトで判定**（PNG / JPEG / WebP / GIF）。Content-Type と拡張子は信用しない。**SVG は不可**（スクリプトを含められる）。
  - 512KB まで、PNG / GIF は 4096px 四方まで、全体で 100 枚まで。本文は読みながら上限を超えたら打ち切る。
  - 保存名は内容の SHA-256 の先頭 16 桁 + 拡張子（`portal/data/icons/`）。同じ画像は同じ参照になる。
- **配信**（`GET /api/icons/{参照}`）: 参照を正規表現で検証し、保存先のフォルダの中のファイルだけを返す。`Content-Security-Policy: default-src 'none'; sandbox`、`nosniff`、1 日キャッシュ（名前が内容のハッシュのため）。`<img>` は Authorization ヘッダーを送れないので、**この GET だけは `PORTAL_TOKEN` の認証を免除**する（一覧・アップロード・削除は認証が要る）。
- **削除**（`DELETE /api/icons/{参照}`）: アップロードしたものだけ。エンティティが使っていると拒否。
- **ノードの右クリック編集**（管理ページのグラフ）: ノードを右クリックすると、メニューの先頭に「✎ 編集…」「🖼 アイコンを変更…」が出る。選ぶと、そのノードの編集ダイアログ（参考画像の Details パネルのイメージ）が開き、アイコン・名前・モデル・ツール・プロンプトを編集できる。中身は左の「選択中」と同じ部品（`Inspector`）で、どちらで変えても同じ台帳に保存される。アイコンは台帳の `icon` を共有するので、ポータルの一覧・フロー・チャットと連動する（ポータルは読み込み時に台帳を取得するので、開き直す・再読み込みで反映）。
- **画面**: 部品 `IconPicker`（既定 / 組み込み / アップロード済み / 新規アップロード、アップロード分は ✕ で削除）を、一覧の「追加・編集」ダイアログと、猫神さま管理の「猫神さま」カードに置いた。表示は、一覧の名前の横、委任フロー（猫神さまと各カード）、チャットの猫神さまの吹き出し・考え中の行、管理ページのノードグラフ。

## 理由・検討した代替案
- 画像を台帳に Base64 で埋める案: 台帳が肥大し、全エンティティの取得ごとに送られる。
- 画像ライブラリ（Pillow 等）でアップロード画像を縮小する案: 新規依存になる。サイズ上限で足りる。サイズが大きい画像（512KB 以内）も 36px などに縮小表示されるだけ。
- SVG を許可して sanitize する案: 防ぎきれないリスクに対し、得るものが小さい。

## 影響・注意
- **画像の利用条件は要確認**（ADR 0030 と同じ。組み込み 3 種は、画像生成ツールで作られた原画の縮小版）。アップロードされた画像の権利は、利用者の責任。
- 表示の対象は、ポータルと管理ページ（要求の範囲）。**Agent Console（`/console`）は対象外**で、従来の絵（猫神さまは固定の画像、ほかは猫の絵）のまま。
- アイコンを台帳の `icon` として持つので、台帳を書き換える手動の編集では、存在しない参照を書くと次の保存で 400 になる。
