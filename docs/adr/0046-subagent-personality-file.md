# 0046 サブオーケストレーターごとの personality.md（ファイルを正にして、定義へ自動同期）

- 状態: Accepted（[0044](0044-admin-ui-and-subagent-persona.md) の性格の保存先を更新）
- 関連: [0021](0021-nekogamisama-personality.md)、要件 [rev3](../requirements/20261025-rev3-admin-ui-and-persona.md)

## 背景
猫神さまは `nekogamisama/personality.md` を `@` で取り込む。サブエージェントの定義ファイルは `@` 取り込みが効かないため、0044 では定義の本文の節に直接書いていた。「サブオーケストレーターごとに personality.md を用意したい」という要望に応える。

## 決定
- 性格は `nekogamisama/personalities/<名前>/personality.md` に置く。形式は猫神さまの `personality.md` と同じ（一人称・呼びかけ・口調・性格・ふるまい）。**このファイルが正**。
- 置き場を `.claude/agents/` の外にしたのは、そこの `.md` は定義ファイルとして走査・読み込みされ、フロントマターのないファイルを置くと扱いが不定になるため。
- 定義ファイルの本文の「## 性格・話し方」の節は、**ファイルから自動生成**する（自動生成と明記するコメント付き）。サブエージェントは追加の読み込みなしで性格を使え、Read ツールがなくても動く。
- 同期のタイミング: 画面からの保存、性格の取得（`GET /api/entities/{id}/personality`）、API の起動時。手で編集したファイルは、取得か再起動で節に反映される。
- ファイルがないとき: 定義の節（手書きの「## 性格」を含む）を読む。保存するとファイルができ、節は置き換わる。既存の定義は壊さない。
- 名前の変更でフォルダも移す。削除すると trash へ退避する。
- 検査（文字数、見出しの禁止、`@` の置換）は猫神さまと同じ。

## 影響・注意
- 定義の節を直接書き換えても、ファイルがあれば次の同期で上書きされる。直すのはファイルの方。
- 試験: ファイルの作成・手編集の反映・起動時の同期・名前変更・削除・手書きからの移行（API）。
