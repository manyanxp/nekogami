# 0024. ポータルのパネル配置（4 パネルのドッキング）と、委任フロー・トレースの独立

- 状態: Accepted（[ADR 0022](0022-portal-layout-and-delegation-flow.md) の画面配置と、フロー図の表現を置き換える）
- 日付: 2026-10-24

## 背景
rev2 の要求 G1〜G4。ADR 0022 では、「一覧」と「チャット」の 2 ペインを上下左右に配置換えでき、委任フローとトレースはチャットの下のタブだった。

## 決定
### パネルと領域
- パネルは 4 つ: **一覧・チャット・委任フロー・トレース**。領域は 3 つ: **左の列・右の列・下の行**。各領域にパネルを順番つきで置く（列は縦に積み、下の行は横に並べる）。
- 既定: 左の列に 一覧 → 委任フロー → トレース、右の列にチャット。サイズは右の列 420px、下の行 260px、高さの比は 一覧 2 : フロー 3 : トレース 1.6（チャット 1）。
- **移動**: パネルのヘッダー（⠿）をドラッグし、領域の中の位置（既存のパネルの中点との比較で決まる挿入位置）に落とす。ドラッグ中は、空の領域も落とし先として表示され、挿入位置に線が出る。Esc で取り消し。ボタンなどの操作部品の上や、6px 未満の移動は、ドラッグにしない。
- **サイズ変更**: 左右の列の境界（右の列の幅）、上と下の行の境界（下の行の高さ）、領域の中のパネルの境界（高さまたは幅の比）。ダブルクリックで既定（パネルの境界は均等）。範囲を制限する（パネルは境界の動かしすぎで消えない: 合計の 12% 以上）。
- 空の領域は閉じる（列が 1 つだけなら、残りの列が全幅になる）。
- 状態は `localStorage`（`portal.layout.v2`）に保存。パネルの欠落・重複・未知の ID など壊れた配置は、既定の配置に戻す（サイズは活かす）。800px 以下の幅では、縦に積む。
- ロジック（検証・移動・挿入位置・サイズ）は DOM に触れない `layout-model.js`、DOM 操作は `layout.js`。

### 委任フロー（`flow-model.js` / `flow.js`）
- 参考画像（Agent Console のフロー図）と同じ、上から下への流れ: 指揮役（猫神さま、破線の枠）→ **委任先を選ぶ**（選ばれた相手の一覧）→ **委任先のカード**（名前・モデル・進捗バー・「実行中 n / ✓ x/y 完了」・ツール数・配下の点・今の動き）→ **結果を統合して回答**。実行中の要素は光り、つながる線は色が付く。
- カード: 委任設定で wired な項目（agent 型は呼ぶエージェントの配下、session 型は別セッションの指揮役の配下）。呼ぶ相手が委任設定にも配下にもないとき（猫神さまの直接の呼び出しなど）は、破線の動的なカード。
- **実行回数は 2 つの経路から数え、多い方を採る**: ツール呼び出し（`route` の PreToolUse と、同じ `toolUseId` の PostToolUse）と、`SubagentStart` / `SubagentStop`。フックの設定でどちらか一方しか届かなくても、開始と完了が分かる。
- 状態は、配下の集計から決める（1 つでも実行中なら実行中、動いたものがあって実行中がなければ完了）。

### トレース（`trace-model.js` / `trace.js` 相当は `chat.js`）
- 独立したパネル。上に「選ばれたエージェント」のチップ、下に「セッションログ」風の表（時刻・誰・内容。誰は種別で色分け、選択の行は強調、最後の行に下線）。
- イベントの取り込み（`reduce`）は DOM に触れない純粋ロジックで、フロー図とログの両方の元になる。

### 一覧
- 「ランタイム」の列を削除した（登録・編集フォームのランタイムの項目は、Docker の起動・停止（ADR 0009）に必要なので残す）。

## 理由・検討した代替案
- パネルを自由に浮かべる（重ねる）案: 重なり・はみ出し・前後の管理が増える。3 つの領域への順番つきのドッキングで、移動とサイズ変更の要求を満たせる。
- 配置の木構造（任意の分割）: 柔軟だが、個人用の画面には過剰。
- フロー図の SVG の維持: 参考画像のようなカード（進捗バー・数値・点）は、HTML の方が作りやすく、Agent Console のフロー図と同じ見た目にそろえられる。

## 影響
- 良い点: フローとトレースを別々に置ける。参考画像と同じ流れで、進捗が分かる。
- 制約・注意:
  - 以前の配置（`portal.layout`）は引き継がない（新しいキー）。
  - 下の行に置いたパネルは、幅が狭いと内容が窓の中で隠れる（パネルの中でスクロールする）。
  - 実行回数の数え方は、両経路が同時に届く場合は重複を避けるため、足し算ではなく最大値を採る。
