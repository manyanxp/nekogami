# 0041 Python ノードと入力ノード

- 状態: Accepted
- 関連: [0038](0038-python-execution-sandbox.md)（実行役）、[0040](0040-llm-node.md)（ノードの公開と接続の確認）、要件 [rev2](../requirements/20261025-rev2-llm-node-tree-dynamic-agents.md)（6(a)、7）

## 背景
rev2 の要求 7: Python をツールのノードにしたい。任意の関数を作り、引数（Python 標準のデータ型）を使え、入力情報は別のノードとして作り、型と値を書ける。出力は、つないだ担当へ返す。
これまでの Python 実行（0038）は、ディレクトリのノードに「Python 実行」を許し、担当が**毎回コードを書いて**渡す形だった。

## 決定
- **Python ノード**（`kind: python`）: 関数のコード（`code`）と関数名（`func`、既定 `main`）を持つ。担当は、`run` ツールに引数（JSON）を渡して関数を呼ぶ。MCP サーバー名は `py-<名前>`（ディレクトリ `dir-`、LLM `llm-` と同じ作り）。
- **引数は型注釈から読む**: API が、コードを**実行せず** `ast` で読み、各引数の名前・型・既定値を取り出す。型注釈のない引数、`*args`・`**kwargs`、`async`、定数でない既定値は、登録時に拒否する。型は Python 標準の `str / int / float / bool / list / dict / tuple / set`（`list[int]` のような添字つきは外側の型で扱う）。
- **入力ノード**（`kind: input`）: 引数名（`param`）・データ型（`dtype`）・値の文字列（`value`）を持つ。値は型に従って読めなければ登録できない（`int` は整数、`bool` は true/false、`list`・`tuple`・`set` は JSON の配列、`dict` は JSON のオブジェクト）。読んだ値は `parsed` に持つ。
- **入力ノード → Python ノード**にワイヤーでつなぐ（Python ノードの `input_ids`）。つなぐと、同名の引数の**既定値**になる。**担当が引数を渡せば、そちらが優先**する。引数名・型が合わないつなぎ、同じ引数に 2 つのつなぎは拒否する。つないだあとに、合わなくなる変更（コード側も入力側も）も拒否する。入力ノードは担当にはつなげない。
- **実行**: Agent Console が、ノードのコードに呼び出しを足したプログラムを、`py-sandbox`（ネットワークなし・30 秒・512 MB。0038）で実行する。`tuple` と `set` は JSON の配列で運び、実行側で型に戻す。戻り値は JSON にして返す（`set` は並べ替え、それ以外の型は `repr`）。標準出力と標準エラーも返す。**ファイルは渡さない**（ディレクトリのノードとは独立）。
- **接続の確認**: 呼ぶたびに、ノードが台帳にあり、呼んだ担当が接続している（定義ファイルの `tools` に `mcp__py-<名前>__*`）ことを確かめる。特定できなければ拒否する（0037・0040 と同じ）。担当に新しくつなぐ・外す扱いは LLM ノードと同じで、サブオーケストレーターへの接続は委任先の担当に反映される。
- **`py-analyst`（要求 6）**: (a) Python ノードで、ファイルなしに関数を呼べるようにした。`py-analyst` は「コードを自分で書いて実行する担当」として残す。(b) 担当を他の担当がツールとして呼ぶ仕組みは、第 4 段階で作る。

## 理由
- 「毎回コードを書かせる」より、管理者が確認した関数を呼ばせる方が、結果が安定し、危険も小さい。
- コードを API で実行せず `ast` で読むので、登録時に任意コードが動かない。実行は常に、隔離した実行役の中。
- 値の既定値と上書きの両方を許すことで、「データはノードで用意し、担当は必要なところだけ変える」ができる。

## 影響・注意
- Python ノードのコードは管理者が書く。担当が書き換えられるのは**引数だけ**で、コードは変わらない。
- コードに書いた内容は、台帳（`portal/data/registry.json`）に載る。**秘密情報（キー・パスワード）を書かない**。
- 実行役はネットワークがないので、外部 API は呼べない。ライブラリは `py-sandbox` に入っているもの（numpy・pandas など。0038）。
- 返り値が 20000 文字を超えると切り詰める。
- 追加の依存はない（標準の `ast` のみ）。ライセンス台帳に変更なし。
- 試験: コードの読み取り・値の検証・つなぎの検査・担当への反映（API）、引数の解決・プログラム生成・結果の整形・接続の確認（Console）、グラフの接続可否（画面）。実機で、ネットワーク遮断・30 秒の時間切れ・既定値の上書きを確認した。
