# 0028. LINE 風チャット・考え中の猫 GIF・フロー図の担当 UUID

- 状態: Accepted
- 日付: 2026-10-24

## 背景
rev2 の追加要求: ① 猫神さまとのやり取りを LINE のように吹き出しで見られるエリア ② 考え中は走る猫のアニメーション GIF ③ 猫神さまが開始したサブオーケストレーター・エージェントの動作を、担当する UUID をもとに Agent Console で表す。

## 決定
- **LINE 風**: ポータルのチャットは、1 件を「行」（相手は左に猫のアイコン、自分は右。吹き出しの下に時刻）で表す。吹き出しは `textContent` のみ（HTML を解釈しない）。meta・error・help は従来の帯。
- **考え中の GIF**: 走る猫の GIF を `scripts/gen-neko-gif.py` で生成する（Python の標準ライブラリだけ。LZW も自前）。ポータル（`/img/neko-run.gif`）と Agent Console（`/neko-run.gif`）の「考え中」で使う。透明背景でテーマを問わない。外部の画像・ライブラリは使わない。
- **担当 UUID**: Agent Console は、ポータルの台帳（`portal/data/registry.json`、`REGISTRY_FILE` で変更可）から名前 → UUID を読み（`ids.mjs`）、`GET /api/ids` で配信する。UUID の形と名前を検証してから出す。フロー図のオーケストレーターと各カードに、先頭 8 桁を出す（全文はツールチップ）。台帳が無ければ何も出さない。

- **反映**: 相手の一覧は定義ファイルと委任設定から要求のたびに作る（ADR 0027）。画面は 10 秒ごと（と、タブに戻ったとき）に `/api/targets` を読み直し、追加・削除・改名を、再読み込みなしで相手の選択肢とフロー図のチームに反映する。今の相手が消えたら、選び直した相手の画面にする。

## 理由・検討した代替案
- ポータルの API から UUID を取る案: Console とポータルが互いに依存する。テーマと同じく、台帳ファイルを読むほうが単純（ADR 0025）。
- 既存の GIF や CSS アニメーション: GIF の指定のため GIF にした。ライセンスの確認が要らない自作とした。

## 追記（2026-10-24）: 考え中の GIF を太陽の猫神さまに変更
ポータルのチャットの考え中は、`icons/sun-cat-loading/sun-cat-running-256.gif`（256px・8 コマ・透過、約 200KB）を `web/public/sun-cat-running.gif` にコピーして使う（96px で表示。ドット絵用の `image-rendering: pixelated` は外した）。Agent Console のチャットの考え中は、従来の `neko-run.gif`（`scripts/gen-neko-gif.py` で生成）のまま。画像の利用条件は、猫神さまのアイコンと同じく要確認（ADR 0030）。

## 影響・注意
- 台帳に無い名前（`test-sub` のような定義だけのもの等）は UUID が出ない。
- Console の吹き出しは従来の作りのまま（LINE 風にしたのはポータルのチャット）。
- 実画面での見た目は未確認（チャット欄は構文確認のみ。GIF と UUID の表示は確認済み）。
