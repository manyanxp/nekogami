# 0004. Agent Console の画面仕様

- 状態: Accepted
- 日付: 2026-10-24

## 背景
チャット入力欄が狭い、ペインの大きさを変えたい、保存した提案書を画面で読みたい、エージェントを見分けやすくしたい、という要望。

## 決定

### レイアウトとリサイズ
- 左: チャット、右: エージェントフロー（上）とトレース（下）。
- 3 つのスプリッターをドラッグで操作する: ① チャット/右列の幅、② フロー/トレースの高さ、③ 入力欄の高さ（44px〜画面の 60%）。
- ダブルクリックで既定値に戻す。サイズは `localStorage`（キー `sage.layout`）に保存。
- 画面幅 900px 以下は縦積みとし、スプリッターは非表示。
- フローの高さは既定で内容なり（最大 330px）。ドラッグ後は上限を外す。

### 猫アイコン
- エージェントフローのカード、orchestrator、トレースの「誰が」欄に SVG の猫を表示。
- 色はモデル（haiku=緑 / sonnet=オレンジ / opus=紫）。模様（無地・額の縞・片目の模様・頬の点）はエージェント名のハッシュで決め、同じ名前は常に同じ猫。
- 実行中は上下に弾み、まばたきする。

### 保存済みドキュメント
- チャット見出しの「📄 保存済み」でモーダルを開く。`reports/`・`research/` の `.md` を更新が新しい順に一覧し、選択したものをマークダウン描画する。Esc・背景クリック・閉じるで閉じる。

## 理由・検討した代替案
リサイズは外部ライブラリを使わず Pointer Events で実装（単一ファイル方針）。猫アイコンは絵文字より色とアニメーションをモデル/状態に連動できる SVG を採用。
