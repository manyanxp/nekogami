# 0021. 猫神さまの性格

- 状態: Accepted
- 日付: 2026-10-24

## 背景
Phase 5 の要求 F5: 猫神さまの性格を設定できるようにする。

## 決定
- **保存先**: `nekogamisama/personality.md`（人が読める Markdown。手で編集してもよい）。項目は、一人称（16 文字）、呼びかけ（16 文字）、口調（80 文字）、性格・ふるまい（1000 文字）。
- **反映**: `nekogamisama/CLAUDE.md` の末尾の節「性格・話し方」に `@personality.md` を置き、Claude Code の取り込み（`@パス`）で読ませる。相対パスは取り込む側のファイルから解決される。**性格は猫神さま自身の返答の言葉づかいにだけ使い、委任先の結果の事実関係・出典・手順・「守ること」は変えない**と同じ節に明記した。
- **API**: `GET/PUT /api/admin/personality`、`POST /api/admin/personality`（`CLAUDE.md` に取り込みの節がなければ足す。足すだけで、既存の内容は変えない）。応答に、プレビュー、ファイルの有無、取り込み済みかどうかを含める。
- **画面**: 管理ページの左に「猫神さまの性格」。口調のひな形（ていねい／親しみやすい／厳格・簡潔／のんびり／老猫（〜じゃ）／猫らしい（〜にゃ））を選ぶと口調欄に入り、自由に直せる。取り込みがないときは警告とボタンを出す。保存は次の会話から有効。
- **安全**:
  - `@` は全角（＠）に置き換えて保存する。性格の文面に書かれた `@/etc/passwd` のような記述が、`CLAUDE.md` の取り込みとして解釈され、任意のファイルが読み込まれるのを防ぐ。
  - 見出し（`#`）は使えない（ファイルの構造と、`CLAUDE.md` の節を壊さないため）。長さに上限。
  - 書き換え前は `portal/data/backups` に退避。

## 理由・検討した代替案
- `CLAUDE.md` の本文に性格を直接書く案: プロンプトの編集（ADR 0016）と同じファイルで競合し、構造化した編集（フォームとプリセット）が難しい。別ファイルにして取り込む方が、役割が分かれる。
- システムプロンプトに差し込む案: Agent Console と CLI の両方で使うため、`CLAUDE.md` の取り込みなら、どちらでも同じに効く。

## 影響
- 良い点: フォームで編集でき、CLI でも Agent Console でも効く。ファイルは手でも直せる。
- 制約・注意:
  - 性格は猫神さまにだけ効く。委任先（Azure Sage など）には伝わらない（依頼文に書けば別）。
  - トレースの語尾「にゃ」（ADR 0012）とは別の仕組み。性格で「〜にゃ」口調を選ぶと、返答本文も猫らしくなる。
  - `CLAUDE.md` を手で編集して取り込みの行を消すと反映されない（管理ページに警告が出る）。
- 確認: 実際の `claude -p` で、一人称「わし」・呼びかけ「おぬし」・「〜じゃ」口調の設定が返答に出ることを確認した。
