# 0012. トレースの発言に「にゃ」を付ける

- 状態: Accepted
- 日付: 2026-10-24

## 背景
Phase 2 の要求 P5: 各エージェントのトレースログに出力される言葉の語尾に「にゃ」を付けたい。

## 決定
- Agent Console のサーバー（`dashboard/server.mjs`）が、イベントを保存・配信する前に変換する。`dashboard/nya.mjs` の `nyaify()`。
- **対象**: エージェント自身の発言だけ。
  - フックの `last_assistant_message`（応答完了・サブエージェント完了の最終メッセージ）
  - SDK のサブエージェントの発話（`subagent_text`）
- **対象外**: ユーザーの入力、ツールの入力と出力（データ）、システム通知、サブエージェントへの指示文（`prompt`）、チャット欄の回答本文、`reports/` に保存するドキュメント。
- **規則**: 文末の句読点・空白・省略表示（`…(+N chars)`）の手前に「にゃ」を入れる（例: `完了しました。` → `完了しましたにゃ。`）。すでに付いていれば何もしない（冪等）。コードブロックで終わる場合は次の行に置く。空や記号だけの発言には付けない。
- 環境変数 `NYA_SUFFIX` で語尾を変更できる。空文字で無効。

## 理由・検討した代替案
- エージェントのプロンプトで「語尾ににゃを付けて」と指示する案: モデル任せで確実でなく、サブエージェントごとに定義を変える必要があり、事実を扱う回答や保存するレポートまで崩れるので不採用。
- ブラウザ側（表示時）で付ける案: 保存済み履歴と配信内容が画面ごとにずれるので、サーバーで統一した。
- ツールの入出力にも付ける案: 検索語やファイルパスなどのデータを壊すので不採用。

## 影響
- 良い点: モデルや定義に依存せず、確実に付く。回答本文とレポートは変わらない。
- 制約: 変換は日本語の文末を想定した単純な規則。英語の発言でも `…ですにゃ` ではなく末尾に「にゃ」が付く。
- 確認状況: `node --test dashboard/nya.test.mjs` の 7 件が通過（Node v22）。`server.mjs` の構文チェックも通過。実際の Claude との会話でのトレース表示は未確認。
- 関連: `dashboard/nya.mjs`、`dashboard/nya.test.mjs`、`dashboard/server.mjs`
