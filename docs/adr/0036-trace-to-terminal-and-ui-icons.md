# 0036. トレースのパネルを廃止してターミナル窓に統合、UI アイコン

- 状態: Accepted（[0024](0024-portal-panels-and-flow-view.md) のパネル構成と、[0033](0033-terminal-windows.md) の「既存のトレースパネルはそのまま」を置き換える）
- 日付: 2026-10-25

## 背景
rev1 の要求: ポータルのトレース画面を削除し、一時的に表示するターミナルに表示する。`Cat_Symbols_Reference_24px` のアイコンを UI に反映する。

## 決定
- **トレースのパネルを廃止**: ポータルのパネルは 3 つ（一覧・チャット・委任フロー）になる。トレースは、担当ごとのターミナル窓（ADR 0033）で見る。`TracePanel.tsx` は削除した。トレースの計算（`trace-model.ts`）は、委任フローとターミナル窓が使うので残す。
- **保存済みの配置**: 古い配置にトレースが残っていても、`normalize` がトレースだけを除き、他の配置とサイズは活かす。
- **UI アイコン**: `icons/Cat_Symbols_Reference_24px/svg` から 27 個を `web/public/ui-icons/` にコピーし、`Icon` コンポーネント（`<img>`、装飾なので `alt=""`）で、主要なボタンの文字の隣に置く。反映先: ポータルのヘッダー、一覧の操作、チャットの送信・停止・リセット、管理ページのツールバーとユーザー管理、ユーザーメニュー。
- 色は、素材の色のまま使う。暗い背景でも明るい背景でも、白い縁取りで読める（ヘッドレス Edge で、ダーク・ライトの両方を確認した）。
- 素材の扱い: 本プロジェクトで作成・生成したもので、**MIT の対象外・このアプリ専用**（NOTICE.md、ライセンス台帳に追記）。

## 影響・注意
- 猫神さま自身の（呼び先ではない）ツール呼び出しは、ターミナル窓には出ない。窓は呼ばれた担当ごとのため。それが必要なら、窓の対象に猫神さま自身を加える（今回は見送り）。
- トレースの全体一覧（チップ）は、ポータルから無くなった。Agent Console `/console` には、従来どおり全トレースがある。
- アイコンは約 330 KB（27 個）で、画面の読み込みに影響は小さい。
- 関連: `web/src/components/Icon.tsx`、`web/src/lib/layout-model.ts`
