# 要件資料: 猫神さま管理ページとノードグラフ — Phase 3

- 元資料: [2026-10-24.add_requirement.md](../add_requirement/2026-10-24/2026-10-24.add_requirement.md) の「1.3 要求 Phase3」
- 日付: 2026-10-24（Q7・Q8 を追記） / 状態: 実装済み（初版）

## 1. 目的
猫神さまを「削除できない管理者エージェント」として守り、専用の管理ページから扱えるようにする。ポータルの一覧は日常の対象（サブオーケストレーター以下）に絞ってツリーで見やすくし、構成の編集は Blueprint 風のノードグラフでできるようにする。

## 2. 要求と対応

| # | 要求 | 対応 | 実装 / 決定 |
|---|---|---|---|
| Q1 | 猫神さまのエージェントは消せない（管理者エージェント） | 台帳の `protected` フラグ。バックエンドが削除（`cascade` 含む）・無効化・改名・親の変更を **403** で拒否する。フラグは API から変更できない | ADR 0013 |
| Q2 | 猫神さまは専用の管理ページで管理できる | `/admin.html`。猫神さまの状態（説明・モデルの編集）、台帳の件数、委任先設定との突き合わせ、ノードグラフ | ADR 0013 |
| Q3 | 管理ページはポータルから移動できる | ポータルのヘッダーに「🐾 猫神さま管理 →」。管理ページに「← ポータル」 | ADR 0013 |
| Q4 | ポータルの一覧にはサブオーケストレーター以下を表示 | 猫神さまを一覧から除き、その子を最上位として表示 | ADR 0013 |
| Q5 | ツリー表示でトグルにより表示・非表示 | ▼/▶ で子を折りたたみ・展開。「展開」「折りたたみ」で一括操作。状態はブラウザに保存。検索・種別フィルタ中は一致を見逃さないよう折りたたみを無視 | ADR 0013 |
| Q6 | サブオーケストレーター、エージェントをノードグラフで新規追加・削除・ツール接続（Unreal Engine の Blueprint のように） | 管理ページのノードグラフ（SVG、依存ライブラリなし）。出力ピン → 入力ピンのドラッグで親子の付け替え・ツール接続、ツールバーで追加、Delete キーで削除、ノードの移動は保存 | ADR 0014 |
| Q7 | ノードグラフ編集の中でモデルを選択できる | 選択したノードの詳細（左のパネル）と、追加ダイアログにモデルの選択肢（別名 `haiku` / `sonnet` / `opus` / `inherit`、フルのモデル ID）。猫神さまのカードでも選択可。台帳のモデルが定義ファイルと異なると警告を出す | ADR 0014 |
| Q8 | ポータル画面に猫神さまとチャットできる入力エリア | 一覧画面の右にチャット欄。ポータルのバックエンドが Agent Console へ中継し、猫神さまに話しかけて返答をストリーミング表示する | ADR 0015 |

## 4. 制約と確認
- 新規ライブラリなし。ノードグラフのライブラリ（React Flow、litegraph など）は使わず、ブラウザ標準の SVG で実装した。ライセンス確認は不要。
- **ツール接続は台帳上のメタ情報です。** エージェント定義（`.claude/agents/*.md` の `tools:`）や実際の権限は変えません（ADR 0014）。

## 5. 範囲外・将来
- 範囲外: ノードグラフの操作でエージェント定義ファイルや `suborchestrators.json` を書き換えること（モデル・ツール接続を含む）、グラフ上での Docker 起動・停止、ポータルのチャットでの Azure Sage など他の相手との会話、トレース（ツール呼び出しなど）のポータル表示。
- 将来: 台帳のツール接続を `.claude/agents/*.md` の `tools:` に書き出す（差分確認つき）、サブオーケストレーター作成時に委任設定とフォルダの雛形を生成する。
