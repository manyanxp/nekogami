# 要件資料: Agent Console の汎用化・画面配置・フロー図・性格 — Phase 5

- 元資料: [2026-10-24.add_requirement.md](../add_requirement/2026-10-24/2026-10-24.add_requirement.md) の「1.5 要求 Phase5」
- 日付: 2026-10-24（F6・F7 を追記し、フロー図が光らない不具合を修正） / 状態: 実装済み（初版）。実際の Claude の会話での表示は一部未確認（§6）

## 1. 目的
Azure 専用の見た目だった Azure Sage Console を「Agent Console」にし、猫神さまの委任先のどのサブオーケストレーターとも話せるようにする。ポータルは画面の配置とサイズを自由にし、猫神さまの委任の流れをフロー図で見せる。猫神さまには性格を設定できるようにする。

## 2. 要求と対応

| # | 要求 | 対応 | 実装 / 決定 |
|---|---|---|---|
| F1 | Azure Sage Console の名称を Agent Console にする | 画面のタイトル・ヘッダー、起動メッセージ、`package.json` の名前を変更。ドキュメントも Agent Console に統一。Docker Compose のサービス名 `azure-sage` とフォルダ名 `azure-sage-agent` は、既存の運用を壊さないため据え置き（のちにルートのフォルダ名を `nekogami` に変更済み） | ADR 0020 |
| F2 | Agent Console を他のサブオーケストレーターでも使えるようにする | ヘッダーの「相手」で、猫神さま・Azure Sage・猫神さまの委任先一覧（`suborchestrators.json`）の各項目（session 型はそのフォルダで、agent 型はそのエージェントをメインにして）を選んで話せる。会話は相手ごとに別（セッションも別）で、切り替えると、その相手の会話を再表示する。一覧は委任先の編集に自動で追随 | ADR 0020 |
| F6 | Agent Console は、使うエージェント毎にフローが変わる | 選んだ「相手」で、フロー図が切り替わる: タイトルと指揮役のカードは相手の名前、カードは相手のチーム（猫神さまは委任先、ほかは `.claude/agents/<相手の名前>/` の定義）を待機状態で並べ、動いたものが実行中・完了になる。委任先の名前（`news-sub`）と実際に動くエージェント（`news-agent`）は 1 枚にまとめる。別セッションへの委任（`delegate.sh`）は、委任先のカードを実行中にする。タイムラインも相手ごとに組み直す | ADR 0020 |
| F7 | Agent Console を、ポータルのサブオーケストレーターの一覧から、専用のボタンでダイアログとして表示する | 一覧のサブオーケストレーターの行に「🖥 Console」。押すと、その相手を選んだ状態の Agent Console が、ダイアログ（iframe）で開く。サイズ変更・別タブで開く・閉じるに対応。委任設定にない行は押せない | ADR 0020 |
| F3 | ポータルのチャットとサブオーケストレーターの一覧を、マウスで配置変更・サイズ変更できる | 各ペインのヘッダー（⠿）をドラッグして、上・下・左・右に配置換え。間のバーをドラッグしてサイズ変更（ダブルクリックで既定に戻す）。状態は保存 | ADR 0022 |
| F4 | 猫神さまが委任しているサブオーケストレーターを、フロー図とトレースログで表示する | チャット欄の下の「委任のフローとトレース」に、タブ「フロー図」（猫神さま → 委任先 → 配下。会話中に選ばれたものが光る）と「トレースログ」（従来の時系列とチップ） | ADR 0022, 0019 |
| F5 | 猫神さまの性格を設定できる | 管理ページの「猫神さまの性格」（一人称・呼びかけ・口調・性格）。`nekogamisama/personality.md` に保存し、`CLAUDE.md` が `@personality.md` で取り込む。猫神さま自身の言葉づかいだけに効き、手順・出典・守ることは変えない | ADR 0021 |

## 4. 制約と確認
- 新規ライブラリなし。配置換え・フロー図も、ブラウザ標準の API（Pointer Events、SVG、localStorage）で実装した。
- Claude Code / SDK の仕様（公式ドキュメントで確認）: `CLAUDE.md` は `@パス` で別のファイルを取り込める（相対パスは取り込む側のファイルから。作業ディレクトリの外のファイルは初回に承認が要る）。Agent SDK の `query()` の `agent` オプションで、メインスレッドを `.claude/agents/` の定義にできる。

## 5. 範囲外・将来
- 範囲外: ポータルのチャットで猫神さま以外と話すこと（猫神さま固定。他の相手は Agent Console）、サブオーケストレーターごとの性格、Docker Compose のサービス名の変更。
- 将来: フロー図のズーム・パン、トレースの履歴（過去の依頼の切り替え）、性格のプリセット保存。
