## 1. 要求と対応
| # | 要求 | 対応 | 決定 |
|---|---|---|---|
| 1 | ノード編集エリアの左側にあるプロパティ情報群をトグルで閉じられる。既定は開いている | 管理ページ上部に「プロパティを開く／閉じる」ボタン。左の列を開閉。開閉はブラウザに記憶 | 既定は開く（更新版で変更） |
| 1b | プロパティ毎に開閉できるトグル。既定は閉じている | 左の列の各カード（テーマ・性格・猫神さま・ユーザー・委任先・選択中）を見出しで開閉。選択中のノードがあるときは開く | ADR 0045 |
| 5 | ノードの選択中、猫神さまから繋がっている線を太く強調 | 担当は親子の線、ツール・入力はそれを使う担当までの線を太く表示 | ADR 0045 |
| 6 | Python ノードに入力ノードが接続できない（不具合） | 原因は「関数に同名・同型の引数が必要」だったこと。引数を入力ノードから決める仕様で解消 | ADR 0045 |
| 7 | Python ノードの仕様変更: 入力ノードの接続で引数をプロパティに自動表示／コード欄は処理だけ／実行時に関数を自動生成／終わってから親へ結果を返す | `style: body`。API が引数と関数のソースを作り、Console が実行。旧形式は互換 | ADR 0045 |
| 2 | 右メニューが機能更新されていないので見直す | グラフの右クリックメニューを作り直し。追加できる種類（ディレクトリ・ローカル LLM・Python・入力）、担当の自動作成の切り替え、プロパティを開く、接続の種類ごとの外し方を反映 | 「右メニュー」= グラフの右クリックメニュー |
| 3 | サブオーケストレーターも、猫神さまと同じく性格・口調を設定できる | インスペクタ（と編集ダイアログ）に「性格・口調」。一人称・呼びかけ・口調・性格を、定義ファイルの本文の「性格・話し方」の節に保存 | 保存先は定義の本文の節 |
| 4 | オーケストレーター・サブオーケストレーター・エージェントのノードに、プロンプト以外のプロパティを参照用に表示（編集不可） | ノードに、ツール数・配下の数・状態（無効・定義なし・呼べる担当・自動作成可）を表示。ホバーで、説明・モデル・親・ツール名・タグ・状態・定義のパスの全文 | プロンプトは含めない |
