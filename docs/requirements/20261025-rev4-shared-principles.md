## 1. 要求と対応
| # | 要求 | 対応 | 決定 |
|---|---|---|---|
| 1 | サブオーケストレーターに接続される子エージェント・子オーケストレーターへ、共通指示のプロンプトエリアを追加 | サブオーケストレーターの「🧭 Shared Principles」に本文を書く。保存先は `nekogamisama/shared/<名前>/shared-principles.md` | 渡し方は「子の定義へ自動同期」（選択） |
| 1-1 | 共通プロンプトを使うかをチェックボックスで選べる | 親のパネルの子の一覧、子自身のパネルの両方にチェックボックス | — |
| 1-2 | チェック時は、子へ共通プロンプトとして渡す | チェックした子の定義ファイル本文に「## Shared Principles」の節を自動生成 | 届く範囲は直下の子だけ（選択） |
| 1-3 | 渡された子はマージしたプロンプトで動き始める | 定義ファイルの本文に節が入るため、起動時から自分のプロンプトと一体で読まれる | — |
| 3 | 管理ページのテーマを、Agent Console のエージェントフローにも反映 | フローの固定色（暗色）をテーマ変数に置き換え、モードとアクセント色に追従 | ADR 0048 |
| 4 | 委任フローに、管理ページで削除したサブオーケストレーターが出る。管理ページの変更をポータルにも連動 | 定義ファイルが消えた委任先を画面とファイルから外す。ポータルは復帰時と 20 秒ごとに読み直す | ADR 0048 |
| 5 | 猫神さまはツールを自分で使わず、サブオーケストレーターに任せる。既存のツールは削除 | 委任（Agent・delegate.sh）と、委任先一覧の Read だけ許可。Glob・Grep・Web などは拒否 | 範囲は「委任以外をすべて外す」（選択） |
| 6 | Bash は使わせず Python ノードに任せる。猫神さまにつながる `py-analyst` を削除 | Bash は開けない。`py-analyst` を削除（trash へ退避）。ドキュメントを更新 | ADR 0048 |
| 2 | 既存のノードは、作り直せるなら改修 | 既存の定義ファイルは変更なし。節がないものは「使わない」状態。親の変更・削除、名前の変更にも追従 | — |
