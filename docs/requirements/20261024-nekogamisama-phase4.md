# 要件資料: Claude のエージェントを増やす・編集する — Phase 4

- 元資料: [2026-10-24.add_requirement.md](../add_requirement/2026-10-24/2026-10-24.add_requirement.md) の「1.4 要求 Phase4」
- 日付: 2026-10-24（S4〜S7 を追記） / 状態: 実装済み（初版）。Claude を実際に走らせた動作は一部未確認（§6）

## 1. 目的
Phase 3 までの台帳上のメタ情報だった「モデル・ツール接続」を、Claude Code が実際に読む定義ファイルに反映する。Claude を使うサブオーケストレーターとエージェントを、ポータルのノードグラフから追加でき、モデル・プロンプト・ツールをノードから編集できるようにする。定義は `.claude/agents/` 以下に体系的に置く。

## 2. 要求と対応

| # | 要求 | 対応 | 実装 / 決定 |
|---|---|---|---|
| S1 | Claude を利用したサブオーケストレーターとエージェントを追加できる | ノードグラフの「＋」で、`.claude/agents/<フォルダ>/<名前>.md`（Claude Code のサブエージェント定義）を作って台帳に登録する。サブオーケストレーターは `Agent` ツールを持つ定義で、猫神さまが Agent ツールで呼ぶ。猫神さまの委任先一覧（`suborchestrators.json`）にも `type: agent` で登録する | ADR 0016, 0017 |
| S2 | モデル選択・プロンプト入力・ツール選択をノードから編集できる | モデル: 詳細パネルの選択欄。プロンプト: 詳細パネルのテキストエリア。ツール: ツールのノードとワイヤーでつなぐ。いずれも定義ファイル（frontmatter と本文）に書き込む。猫神さまと Azure Sage は、プロンプトが `CLAUDE.md`、モデルが `.claude/settings.json` の `model` | ADR 0016 |
| S4 | 管理ページの委任先の突き合わせで、台帳と委任設定（`suborchestrators.json`）を編集できる | 突き合わせの表の「編集」「整える」と「＋ 委任先を追加」で、1 つのダイアログから、台帳（登録・説明・モデル・有効・登録の解除）と委任設定（種類 agent / session、呼ぶエージェントまたは実行フォルダ、説明、登録・削除）を同時に編集する。片方にしかない行は、足りない側にチェックが入った状態で開き、保存すると整合する。委任設定の書き換え前は `portal/data/backups` に退避。session 型の `dir` はプロジェクト配下の既存フォルダだけ | ADR 0018 |
| S5 | ノードの編集画面で右クリックのメニューから新規追加できる | グラフ上の右クリック。背景ではサブオーケストレーター・エージェント・サブエージェント・ツールを追加（クリックした位置に置く）。ノードでは、その配下に作れる種別の追加、名前の変更、削除。ワイヤーでは接続を外す | ADR 0018 |
| S6 | サブオーケストレーター・エージェント・サブエージェントの名前を編集できる | 詳細パネルの「名前を変更…」と右クリックメニュー。`name:`・ファイル名・子のフォルダ・委任先一覧の項目が追随する。猫神さまは不可 | ADR 0018 |
| S7 | 猫神さまとのチャットで、どのエージェントが選ばれたかをポータルで可視化する | チャット欄の下に「トレース」。選ばれたエージェントのチップ（種別の色、稼働中/完了、ツール回数、別セッション委任の表示）と、時系列（選択・開始・ツール・完了） | ADR 0019 |
| S3 | `.claude/agents/` 以下で体系的に管理できる | `.claude/agents/<親の名前>/<名前>.md` の規則（サブオーケストレーターは自分の名前のフォルダ）。既存の Azure の 4 エージェントは `.claude/agents/azure-sage/` へ移した。ポータルが定義の追加・親の付け替え（フォルダ移動）・削除（trash へ退避）を行い、手で置いたファイルは取り込み時にフォルダ名から親を決めて登録する。規則から外れたものは管理ページに警告する | ADR 0016 |

## 4. 制約と確認
- 新規ライブラリなし（Python 標準ライブラリのみ。frontmatter は編集する項目だけを差し替える自前の処理）。
- Claude Code の仕様（公式ドキュメント code.claude.com/docs/en/sub-agents で確認）: `.claude/agents/` は再帰的に読まれ、識別は frontmatter の `name`。作業ディレクトリから親へ辿って `.claude/agents/` が読まれる。サブエージェントはさらにサブエージェントを起動できる（既定で 3 層まで）。`tools` を省略すると全ツールを継承する。

## 5. 範囲外・将来
- 範囲外: `permissionMode`・`hooks`・`mcpServers` など権限に関わる frontmatter の編集、他のエージェントのプロンプトに書かれた名前の自動書き換え、`session` 型のフォルダ（`CLAUDE.md` と `.claude/`）の作成（委任先一覧への登録はできる）。
- 将来: エージェントごとの MCP サーバー定義の編集、定義ファイルの差分表示、trash・backups からの復元 UI。
