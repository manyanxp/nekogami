# 要件資料: 画面変更・テーマ・チャットボットと / コマンド（rev2）

- 元資料: [2026-10-24.add_requirement_rev2.md](../add_requirement/2026-10-24/2026-10-24.add_requirement_rev2.md)（参考画像: `docs/add_requirement/2026-10-24/reference-flow.png`）
- 日付: 2026-10-24 / 状態: 実装済み（初版）。実際の Claude の会話での `/` コマンドの振り分けは未確認（§6）

## 1. 目的
ポータルの画面を、委任フローとトレースを独立した、動かせるパネルにする。色（テーマ）を管理ページで選べるようにする。猫神さまに、性格を反映したおしゃべり担当（チャットボット）を加え、チャットから `/名前` でサブオーケストレーター・エージェントを呼び出せるようにする。

## 2. 要求と対応

| # | 要求 | 対応 | 実装 / 決定 |
|---|---|---|---|

| I3 | 猫神さまの考え中のアニメーション GIF を `icons/sun-cat-loading/sun-cat-running-256.gif` にする | ポータルのチャットの考え中の GIF を差し替え（96px 表示）。Agent Console のチャットは従来のまま | ADR 0028 |

## 4. 制約と確認
- 新規ライブラリなし。パネルの移動・サイズ変更・フロー図・テーマ・コマンド候補は、ブラウザ標準の API だけで実装した。

## 5. 範囲外・将来
- 範囲外: パネルの重ね表示（フローティング）、テーマの背景色・フォントの変更、Agent Console のパネルの移動、`/` コマンドの引数の補完。
- 将来: `/` で呼んだ相手の進捗を、チャットの中に表示する。
