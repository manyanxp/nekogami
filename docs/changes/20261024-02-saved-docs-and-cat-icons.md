# 2026-10-24 保存済みマークダウン表示と猫アイコン

- 関連 ADR: 0003, 0004
- 影響範囲: 画面、API（`dashboard/server.mjs`）

## 変更前
- 保存した `reports/*.md` は画面で読めなかった。エージェントは文字名とモデルバッジのみで識別。

## 変更後
- 「📄 保存済み」から `reports/`・`research/` の `.md` を一覧・描画できる。
- エージェントごとに、モデル色 + 名前由来の模様の猫アイコンを表示。

## 差分
- 追加: `GET /api/docs`, `GET /api/doc?path=`（対象は `reports/`・`research/` の `.md` のみ）、ドキュメントビューア、猫アイコン（フロー・orchestrator・トレース）。

## 移行・注意点
- サーバー変更を含むため、ダッシュボードの再起動が必要。
