# 2026-10-24 画面リサイズ対応

- 関連 ADR: 0004
- 影響範囲: 画面（`dashboard/public/index.html`）

## 変更前
- チャット幅は `minmax(340px, 42%)` 固定、入力欄は最大 160px、フローは最大 330px で固定。

## 変更後
- 幅・フローの高さ・入力欄の高さをドラッグで変更でき、`localStorage` に保存。ダブルクリックで既定に戻る。

## 差分
- 追加: スプリッター 3 種、`--chat-w` / `--flow-h` / `--input-h`、`sage.layout` の保存。
- 変更: 入力欄の最大高さを 160px → 60vh、フローの上限はドラッグ後に解除。
- 注意: 900px 以下ではスプリッター非表示。
