# 2026-10-25 Python ノードを「処理だけ」に、左の列の開閉と線の強調（rev3 更新分）

- 関連 ADR: 0045（0044 の左の列の既定を変更）
- 関連要件: [rev3](../requirements/20261025-rev3-admin-ui-and-persona.md)
- 影響範囲: `portal/backend/portal_api/{pynodes,registry}.py`、`dashboard/py-tools.mjs`、`web/src/`

## 変更前
左の列は既定で閉じていた。Python ノードは関数ごと書き、関数に同名・同型の引数がないと入力ノードをつなげなかった。選択中のノードの線は強調されなかった。

## 変更後
- 左の列は既定で開く。各カードを個別に開閉できる（既定は閉じる）。
- ノード選択中、猫神さまから続く線を太くして強調する。
- Python ノードは処理だけを書く。入力ノードをつなぐと引数が自動で決まり、プロパティに表示される。実行時に関数を自動生成し、終わってから結果を親へ返す。旧形式は互換で動く。
- 入力ノードを Python ノードにつなげない不具合を解消した。

## 移行・注意点
- `docker compose up -d --build api neko-brain web`。既存の Python ノードは、読み込み時に形式が判定される。
