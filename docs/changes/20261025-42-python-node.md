# 2026-10-25 Python ノードと入力ノード（rev2 の第 2 段階）

- 関連 ADR: 0041
- 関連要件: [rev2](../requirements/20261025-rev2-llm-node-tree-dynamic-agents.md)（6(a)、7）
- 影響範囲: `dashboard/{py-tools,py-exec,server}.mjs`、`portal/backend/portal_api/{pynodes,registry,definitions}.py`、`web/src/`（管理ページ）

## 変更前
Python を動かすには、ディレクトリのノードに「Python 実行」を許し、担当が毎回コードを書いて渡す必要があった。引数や入力データをノードとして用意することはできなかった。

## 変更後
- ツールの種類に `python`（関数のコード）と `input`（引数名・データ型・値）を追加。管理ページに「Python」「入力」の追加ボタンと編集パネル。
- 担当につなぐと、`run` ツールで関数を呼べる。引数は型注釈から読む（`str / int / float / bool / list / dict / tuple / set`）。コードは登録時に実行せず検証する。
- 入力ノードを Python ノードにつなぐと、同名の引数の既定値になる（担当が渡した値が優先）。型・引数名が合わないつなぎは拒否する。
- 結果（戻り値・標準出力・エラー）は、呼んだ担当へ返す。実行は `py-sandbox`（ネットワークなし・30 秒・512 MB）。
- 検証: API 57 件、Console 47 件、画面 48 件が成功。実機で、既定値の上書き・ネットワーク遮断・30 秒の時間切れを確認した。

## 移行・注意点
- `docker compose up -d --build`。既存のノード・担当には影響しない。
- コードは台帳に載るので、秘密情報を書かない。
