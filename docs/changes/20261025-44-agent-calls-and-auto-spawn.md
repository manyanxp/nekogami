# 2026-10-25 担当を呼ぶ接続と、担当の自動作成（rev2 の第 4 段階）

- 関連 ADR: 0043
- 関連要件: [rev2](../requirements/20261025-rev2-llm-node-tree-dynamic-agents.md)（5、6(b)）
- 影響範囲: `dashboard/{spawn-agent,server}.mjs`、`portal/backend/portal_api/{registry,chat}.py`、`web/src/`（管理ページ、トレース）、`docker-compose.yml`

## 変更前
担当が別の担当を呼べるのは、親子（`Agent` ツール）と猫神さまの委任だけだった。配下で足りないときに担当を増やす手段はなかった。

## 変更後
- 担当の下のピン → 別の担当の上のピンで、「呼ぶ」接続をつなげる（定義の `tools` に `Agent` を足す）。自分自身・猫神さま・定義のない担当・輪は拒否。
- サブオーケストレーターごとに「担当を自動で作ってよい」のスイッチ（既定オフ）。入れると、`spawn` ツールで読み取り専用の使い捨ての担当を作って使える（1 回の依頼で 3 体まで。終われば消える。保存しない）。
- 自動作成の担当の動きを、トレース・ターミナル・Agent Console に「自動作成/<名前>」として出す。
- 検証: API 59 件、Console 52 件、画面 54 件が成功。実機で、自動作成から削除までの通しを確認した。

## 移行・注意点
- `docker compose up -d --build`。既存の担当には影響しない（スイッチは既定オフ）。
- 自動作成のモデルは `SPAWN_MODEL`（既定 haiku）。
