# 2026-10-25 管理ページの見直しと、サブオーケストレーターの性格（rev3）

- 関連 ADR: 0044
- 関連要件: [rev3](../requirements/20261025-rev3-admin-ui-and-persona.md)
- 影響範囲: `web/src/`（管理ページ）、`portal/backend/portal_api/{personality,registry,app}.py`

## 変更前
管理ページの左の列は常に出ていた。右クリックメニューは、ディレクトリ・LLM・Python・入力・自動作成に対応していなかった。性格を設定できるのは猫神さまだけで、グラフのノードは名前とモデルしか出さなかった。

## 変更後
- 左の列を、ボタンで開閉する（既定は閉じる。記憶する）。
- 右クリックメニューを作り直した（追加できる全種類、自動作成の切り替え、プロパティを開く、接続の種類ごとの外し方）。
- サブオーケストレーターの性格・口調を、画面から設定できる（定義の本文の「性格・話し方」の節）。
- ノードに、ツール数・配下の数・状態を表示し、ホバーで全文（プロンプト以外）を出す。
- 検証: API 60 件、画面 57 件が成功。実機で既存の手書きの性格を読めることを確認。

## 移行・注意点
- `docker compose up -d --build api web`。既存の定義ファイルは変えない（性格は、保存したときだけ書く）。
