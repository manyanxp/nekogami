# 2026-10-24 委任先の編集・右クリックメニュー・改名・チャットのトレース（Phase 4 追記）

- 関連 ADR: 0018, 0019（0017 に追記）
- 要件: [20261024-nekogamisama-phase4.md](../requirements/20261024-nekogamisama-phase4.md)（S4〜S7）
- 影響範囲: `portal/`、`dashboard/server.mjs`、`docs/`

## 変更前
委任先一覧（`suborchestrators.json`）は読み取りのみで、手で編集していた。ノードの追加はツールバーのボタンだけ。名前は作成後に変えられなかった。猫神さまとのチャットでは、誰に依頼したかが分からなかった（トレースは Agent Console の画面だけ）。

## 変更後
- 管理ページの突き合わせの表から、台帳と委任設定を同時に追加・編集・削除できる（片方にしかない行は「整える」で、足りない側を登録してそろえる）。
- グラフの右クリックメニューから、新規追加（位置・親つき）、名前の変更、削除、接続の解除ができる。
- サブオーケストレーター・エージェント・サブエージェントの名前を変えると、定義ファイル・子のフォルダ・委任先一覧が追随する。
- ポータルのチャット欄の下に、選ばれたエージェントのチップと時系列のトレースが出る。

## 移行・注意点
- ポータルの再起動が必要（反映済み）。Agent Console も再起動すると、トレースの印付けが効く（古いままだと、ポータルのトレースは空になる）。
- 委任設定にだけある `news-sub`（`news-agent` を呼ぶ `agent` 型）は、表の「整える」で台帳に登録できる。登録済みの `test-sub`（定義ファイルなし）は、同じく「整える」で委任設定に登録できる。
- 台帳だけを外しても委任設定は残る。定義ファイルのあるもの・配下があるものは、表からは台帳の登録を解除できない。
- 未確認: 実際の Claude の会話でのトレース表示、猫神さまが `agent` 型の委任先に依頼して結果を統合する動作。
