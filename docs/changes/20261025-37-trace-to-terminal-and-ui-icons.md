# 2026-10-25 トレースのパネルを廃止、UI アイコン（rev1 の第 1 段階）

- 関連 ADR: 0036、0033、0024
- 関連要件: [rev1](../requirements/20261025-rev1-ui-and-agent-tools.md)
- 影響範囲: `web/src/`（`PortalApp`、`layout-model`、`Icon`、各ボタン）、`web/public/ui-icons/`

## 変更前
ポータルに「トレース」のパネルがあり、ターミナル窓と二重に表示していた。ボタンは文字と絵文字だけだった。

## 変更後
- トレースのパネルを削除。ターミナル窓だけで表示する。
- 27 個のアイコンを、ヘッダー・一覧・チャット・管理ページ・ユーザー管理のボタンに追加。
- 検証: vitest 41 件、型検査が成功。確認用サーバーで、ポータルと管理ページを実際の画面で確認した。

## 移行・注意点
- ブラウザに保存された古いパネル配置は、自動で直る（トレースだけが除かれる）。
- `docker compose up -d --build web` で反映する。
