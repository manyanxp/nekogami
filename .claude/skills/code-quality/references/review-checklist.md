# 完了前チェックリスト

完了報告の前に、以下を上から順に確認する。満たせない項目があれば、その理由を報告に書く。

## 1. 要件
- [ ] 依頼された内容をすべて満たしている
- [ ] 依頼されていない変更（無関係なリファクタリング、フォーマット変更）を混ぜていない
- [ ] 曖昧な点について、仮定したことを把握している

## 2. コード
- [ ] 新規・変更した関数に型が付いている（`Any` / `any` がない、または理由がコメントされている）
- [ ] 例外を握りつぶしていない（空の `except` / `catch` がない）
- [ ] マジックナンバー・曖昧な名前（`data`, `tmp` など）がない
- [ ] デバッグ用の `print` / `console.log`、コメントアウトされたコードが残っていない
- [ ] 理由のない `TODO` がない

## 3. セキュリティ
- [ ] 秘密情報（APIキー、パスワード、トークン）を直書きしていない
- [ ] SQLがパラメータ化されている
- [ ] `eval` / `exec` / `shell=True` / `innerHTML` に外部入力を渡していない
- [ ] ログに個人情報・秘密情報を出していない
- [ ] 外部入力を境界で検証している

## 4. テスト
- [ ] 新しいロジックにテストを追加した
- [ ] バグ修正の場合、再現テストがある
- [ ] 正常系・境界値・異常系を含んでいる

## 5. ツール実行（実際に実行して結果を確認する）
- [ ] フォーマッタ（`ruff format` / `prettier`）
- [ ] Lint（`ruff check` / `eslint`）がエラー0
- [ ] 型チェック（`mypy` / `pyright` / `tsc --noEmit`）がエラー0
- [ ] テスト（`pytest` / `vitest` / `jest`）がすべて成功
- [ ] 警告抑制コメントを追加した場合、対象ルールを限定し理由を書いた

## 6. 報告
- [ ] 変更したファイルと目的
- [ ] 実行したチェックと結果（失敗が残っていれば正直に）
- [ ] 仮定、残課題、気づいた別の問題
